# Release Notes

## v3.8.4 - 2026-06-17

### 面经结论验收更严格

新增覆盖牛客、脉脉、小红书、搜索引擎和官网 JD 的端到端验收样本。系统会验证结果从搜索、抓取、结构化抽取到 Feed 摘要都能形成可追溯问题；官网 JD 只作为岗位证据，不会伪造成真实面试题。

同时，指定目标公司后，非目标公司面经不会再因为“也是面经”进入 Feed。例如搜索 Kimi 时，阿里、字节、百度、腾讯等其他公司的 AI 面经会被过滤掉。

## v3.8.3 - 2026-06-17

### 小红书笔记详情抓取更快

小红书 MCP 客户端从串行改为允许 3 路并发抓取，单条笔记详情超时从 30s 降到 20s，单次搜索抓 5 条笔记的时间从约 100 秒降到约 20 秒。单次网络抖动不再触发 Playwright 浏览器重启（15s 成本），连续 3 次超时才会判定为浏览器失活。

### 数据源授权面板新增"上次验证时间"

授权面板会展示"上次验证：X 分钟前 / X 小时前 / X 天前"，用户能直观看到 Cookie 距上次校验过了多久，而不是只看到一个静态"已保存"。

### Cookie 超过 24 小时自动复验

授权面板每 15 秒刷新一次状态，如果某个数据源距上次验证超过 24 小时（或保存了 Cookie 但从未验证过），会自动触发复验，复验中显示"正在自动复验..."。用户不再需要手动点击校验来确认 Cookie 是否还活着。也可以随时点击"立即复验全部数据源"手动触发。

### 小红书详情阶段识别 Cookie 过期

小红书笔记详情抓取如果遇到"请先登录"提示，系统会立即把小红书标记为"已过期：Login required in fetch"，15 秒内前端会显示过期状态，提示用户重新授权，而不是静默失败让用户以为是没有结果。

## v3.8.2 - 2026-06-17

### Kimi 搜索不再混入产品介绍

实时搜索会在展示前过滤通用搜索引擎里的产品页、官网动态和科普文章。像“Kimi AI with K2.6”“Kimi 官网”“三分钟读懂 Kimi”这类不是面经的内容，不会再因为命中公司名就进入面经 Feed。非面经正文也不会再触发 LLM 抽题。

## v3.8.1 - 2026-06-17

### 来源状态更可信

牛客在公开 API 没搜到内容、且本机没有配置 SearXNG 时，会继续使用免费的 Bing RSS 做 `site:nowcoder.com` 兜底，尽量发现公开牛客面经链接。脉脉 Cookie 如果最近运行被判定过期，授权面板会显示“已过期”，不再因为本地有旧 Cookie 文件而误显示为正常。

## v3.8.0 - 2026-06-16

### 脉脉授权恢复

实时搜索页新增脉脉授权面板。Cookie 过期后，用户可以在本机粘贴新的脉脉 Cookie，系统会先校验再保存；后续脉脉响应中的续期 Cookie 会自动合并，减少频繁手动改配置。

### 结构化分析不再无限等待

帖子正文抓取成功但 LLM 抽取失败、超时或未返回结果时，Feed 卡片会显示明确状态，例如“结构化分析失败”“结构化分析超时”或“未返回结构化结论”，不再一直卡在等待。

### 浅色研究工作台

首页、实时搜索、结果卡片、Agent 进度和面经详情改为浅色 Research Console 风格，信息密度更高，阅读更像研究工具而不是黑色终端。

## v3.7.0 - 2026-06-16

### 免费搜索兜底

没有配置自托管 SearXNG 时，实时搜索、官网 JD 和小红书公开笔记 URL 发现会自动使用无 Key 的免费 RSS 兜底，减少搜索页直接报配置错误的情况。小红书兜底只保留 URL 和摘要候选，正文仍需授权会话抓取，避免把低置信摘要当成真实帖子内容。

## v3.6.0 — 2026-06-16

### 岗位画像工作台

新增 `/role-profile` 页面：用户可以直接输入“阿里+字节的自动化测试工程师”或“Kimi 的大模型 Eval 评测方向”，查看岗位总结、技能权重、面试重点、准备计划、来源状态和证据链。

---

## v3.5.0 — 2026-06-16

### 本地 JD 缓存兜底

岗位画像在实时官网 JD 暂时搜不到时，可以读取本机 `ai-job-radar` 的官方岗位快照来补充职责、要求和业务线索。系统会明确标记这些 JD 是本地快照、未实时校验，避免把缓存误当作最新在招岗位。

---

## v3.4.0 — 2026-06-16

### 岗位画像即时生成

新增 `/api/role-profile/search`：输入“阿里+字节的自动化测试工程师”或“Kimi 的大模型 Eval 评测方向”这类关键词后，系统会解析目标公司和方向，聚合官网 JD 与面经证据，输出岗位定位、技能权重、面试重点和准备计划。证据不足时会明确提示缺口，不把低质摘要伪装成高置信面经。

---

## v3.3.3 — 2026-06-16

### 来源稳定性

Cookie 过期、来源限流、超时或配置缺失时，搜索结果会给出更明确的恢复动作。脉脉 Cookie 可以从项目授权状态自动刷新并重试；牛客和小红书在主链路不稳定时，会用免费 SearXNG 发现公开 URL 作为兜底，减少重要来源直接消失的情况。

---

## v3.3.2 — 2026-06-15

### 官网 JD 来源

搜索结果现在可以出现"官网 JD"来源，优先覆盖字节、阿里/千问/夸克、Kimi/月之暗面等官方招聘入口。用户准备岗位时，不只看到面经，也能看到岗位职责和任职要求这类官方证据。

## v3.3.1 — 2026-06-15

### 免费搜索引擎

搜索引擎来源改为自托管 SearXNG，不再需要 SerpAPI 这类付费 API Key。用户在本地配置 SearXNG 后，可以继续用搜索引擎覆盖官网 JD、公开博客和长尾面经入口。
